# Superhero-analytics
Project Description:
This project focuses on exploratory data analysis (EDA) of a superheroes dataset to uncover meaningful patterns related to powers, physical attributes, publishers, and alignment.
The goal is to derive data-driven insights rather than just visualizations, simulating how a data analyst/business analyst would analyze an entertainment or media dataset.
The project demonstrates the complete analytics workflow starting from data cleaning to insight generation, using Python-based data analysis libraries.
Objective:
•	Analyze superheroes based on publisher, alignment, gender, race, and powers
•	Identify patterns and trends in superhero characteristics
•	Compare Marvel vs DC superheroes across multiple dimensions
•	Generate business-style insights from raw data

Dataset:
•	Dataset contains information about superheroes including:
o	Name
o	Publisher (Marvel, DC, etc.)
o	Alignment (Good, Bad, Neutral)
o	Gender, Race
o	Physical attributes (Height, Weight)
o	Superpowers
•	Source: Publicly available superhero dataset (Excel format)

Key Analysis Performed
•	Data cleaning and handling missing values
•	Exploratory Data Analysis (EDA)
•	Distribution analysis of superheroes by:
o	Publisher
o	Alignment
o	Gender and race
•	Comparative analysis between Marvel and DC
•	Power frequency and dominance analysis
•	Visualization using charts and plots


Key Insights
•	Marvel and DC dominate the superhero universe in terms of character count
•	Majority of superheroes are aligned as “Good”, with fewer villains
•	Certain powers (e.g., super strength, flight) are significantly more common
•	Gender imbalance exists, with male superheroes being more prevalent
•	Distinct differences observed between Marvel and DC character attributes
